# Direktori Dokumen Resmi & SK Masjid Kampus UMS

Folder ini diperuntukkan untuk menyimpan berkas dokumen resmi, Surat Keputusan (SK), dan arsip legalitas Masjid Kampus UMS, antara lain:

1. `sk-pendirian-masjid-sudalmiyah.pdf` - Surat Keputusan Pendirian & Penetapan Nama Masjid Hj. Sudalmiyah Rais.
2. `sk-struktur-takmir-masjid.pdf` - Surat Keputusan Susunan Pengurus Takmir Masjid Kampus UMS.
3. `piagam-masjid-percontohan-aum.pdf` - Piagam Penetapan Masjid Percontohan Amal Usaha Muhammadiyah (AUM).
4. `pedoman-pengelolaan-masjid.pdf` - Buku Panduan Tata Kelola & SOP Masjid Kampus UMS.

Berkas yang diletakkan di dalam folder ini dapat diakses secara publik melalui URL `/dokumen/[nama-berkas]` dan diunduh langsung melalui halaman Sejarah Masjid (`/sejarah`).
